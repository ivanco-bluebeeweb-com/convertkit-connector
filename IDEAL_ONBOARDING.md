# ConvertKit (Kit) Connector — Ideal Onboarding Experience

1. **Step 1: Access Kit Settings**
   - Log into Kit (ConvertKit) dashboard -> Settings -> Advanced.
2. **Step 2: Generate API Token**
   - Copy your v4 API Key or create a personal access token.
3. **Step 3: Connect to Imperal**
   - Provide an optional connection label.
   - Enter your API Key / Bearer Token.
   - Click "Connect Kit".
4. **Step 4: Verification & Readiness**
   - The connector verifies account identity via `GET /account`.
   - On success, the connection is active and tools become available.
